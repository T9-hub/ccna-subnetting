# แบ่ง Subnet WAN ให้เล็กลง (/26 → /30)

## ทำไมต้องเปลี่ยน

|              | วง WAN เดิม        | วง WAN ใหม่        |
| ------------ | ------------------ | ------------------ |
| Subnet       | `192.168.1.128/26` | `192.168.1.128/30` |
| Mask         | `255.255.255.192`  | `255.255.255.252`  |
| Usable Hosts | 62                 | 2                  |

ลิงก์ Router1 ↔ Router2 ใช้แค่ **2 IP** (Router ฝั่งละ 1) การใช้ /26 จึงเปลือง IP ไป 60 ตัว

**สิ่งที่เปลี่ยน:** Subnet Mask ของพอร์ต Serial ทั้งสองฝั่งเท่านั้น
**สิ่งที่ไม่เปลี่ยน:** IP Serial ยังเป็น `.129` และ `.130` ส่วน LAN 1 และ LAN 2 ยังเป็น /26

---

## ภาพรวมการแบ่งวง

เรากำลัง **แบ่ง Subnet เดิมต่ออีกชั้น** โดยนำวง .128/26 มาแบ่งย่อย

```text
192.168.1.0/24
├── 192.168.1.0/26     LAN 1 (เหมือนเดิม)
├── 192.168.1.64/26    LAN 2 (เหมือนเดิม)
├── 192.168.1.128/26   ← นำวงนี้มาแบ่งต่อเป็น /30
└── 192.168.1.192/26   ยังไม่ได้ใช้
```

---

## ทำไมถึงเป็น /30

เริ่มจาก **จำนวน Host ที่ต้องการ**

1. ต้องการ 2 Host ที่ใช้ได้
2. หา Host Bits (h) ที่ `2^h − 2 ≥ 2`
   - h = 1 → 2¹ − 2 = 0 (ไม่พอ)
   - h = 2 → 2² − 2 = **2** (พอดี)
3. Host Bits = 2 → Network = `32 − 2 =` **/30**

**ดูในมุมของ Bits**

```text
เดิม /26: [ Network 26 Bits ][ Host 6 Bits ]                  → 2^6 − 2 = 62 Hosts
ใหม่ /30: [ Network 26 Bits ][ ยืม 4 Bits ][ Host 2 Bits ]     → 2^2 − 2 = 2 Hosts
                              └── ยืมจาก Host เดิม
```

| รายการ            | สูตร                 | ค่า       |
| ----------------- | -------------------- | --------- |
| Bits ที่ยืม       | 6 − 2                | 4 Bits    |
| Network Bits ใหม่ | 26 + 4               | /30       |
| จำนวนวงย่อย       | 2^(Bits ที่ยืม) = 2⁴ | **16 วง** |
| Address ต่อวง     | 2²                   | 4         |
| Usable ต่อวง      | 4 − 2                | **2 IP**  |

---

## Subnet Mask ของ /30

```text
/30 = 255.255.255.252
256 − 252 = 4   ← ขนาดของแต่ละวง (Block Size)
```

วงย่อยเริ่มทีละ 4: `.128`, `.132`, `.136`, `.140` ... ถึง `.188` (รวม 16 วง = 64 ÷ 4)

---

## วง WAN ที่ใช้ (วงแรก)

| รายการ                     | Address         |
| -------------------------- | --------------- |
| Network Address            | `192.168.1.128` |
| First usable → **Router1** | `192.168.1.129` |
| Last usable → **Router2**  | `192.168.1.130` |
| Broadcast Address          | `192.168.1.131` |

วงถัดไปเริ่มที่ `192.168.1.132/30` (เก็บไว้ใช้กับลิงก์ Router คู่อื่นได้)

---

## คำสั่งที่ต้องแก้

เปลี่ยนเฉพาะ Mask บนพอร์ต Serial ของทั้งสอง Router

```cisco
Router1(config)# interface serial 0/0/0
Router1(config-if)# ip address 192.168.1.129 255.255.255.252

Router2(config)# interface serial 0/0/0
Router2(config-if)# ip address 192.168.1.130 255.255.255.252
```

EIGRP ไม่ต้องแก้ เพราะ `network 192.168.1.0` ยังครอบคลุมพอร์ตเหล่านี้อยู่

ตรวจซ้ำ:

```cisco
show ip interface brief
show ip eigrp neighbors
show ip route
ping 192.168.1.130
```

## จุดที่มักจดผิด

| ที่มักเขียน                          | ที่ถูกต้อง                                        |
| ------------------------------------ | ------------------------------------------------- |
| `2^6 − 2 = 126`                      | `2^6 − 2 =` **62**                                |
| ยืม 2 Bits → 4 วง (ใช้กับ /24 → /26) | /26 → /30 ยืม **4 Bits → 16 วง** อย่าปนสองขั้นตอน |
| `256 − 252 = 4` คือ "จำนวนวง"        | 4 คือ **ขนาดของแต่ละวง** จำนวนวง = 64 ÷ 4 = 16    |

จาก /26 เปลี่ยนเป็น /30 คือเอา Host Bits เดิม 4 Bits มาใช้แบ่ง Subnet เพิ่ม:

ทำไมถึงเป็น /30 เพราะว่า
เดิม:
[ Network เดิม 26 Bits ][ Host 6 Bits ]
/26 หมายถึงใช้ 26 Bits เป็น Network Portion จาก IPv4 ทั้งหมด 32 Bits จึงเหลือ Host Portion 6 Bits

2^6 - 2 = 126 Usable

    steal มาเท่าไหร่คือ วง Subnet
    เรา steal มา ของเดิมเลยคือ /24 + 2  =  steal มา 2 = 2^2 = 4 วง

ใหม่ /30:
[ Network เดิม 26 Bits ][ แบ่งเพิ่ม 4 Bits ]
[ Host 2 Bits ]

    ก็คือ เราต้องการ 2 Host usable
    มี 26 network
    เหลือ Host ตอนนี้ทั้งหมด 32-26 = 6 Host
    ต้องการ 2 Host ไป steal bit มา 4
    ได้ว่า 26 + 4  = /30 net ที่เหลือคือ 2 Host

    2^2 = 4 host
        but -2 usable ใช้ได้เเค่ 2 IP

    มีทัังหมด 2^ steal bit = 2^4 วงเน็ตของ network นี้


    /30 new subnet = 255.255.255.252

    256-252 = + 4 ได้ทั้งหมด 4 วง
                    เเต่ละวงได้ 2 IP ที่ใช้ได้

    192.168.1.129 → First usable → Router1
