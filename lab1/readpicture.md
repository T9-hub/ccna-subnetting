## 🌐 การเชื่อมต่อ PC → Switch ในโลกจริง

### 1. PC1 FastEthernet0 → SW1 FastEthernet0/1

**ฝั่ง PC1**

- คอมพิวเตอร์ทั่วไปมีพอร์ต LAN สำหรับเสียบสาย Ethernet โดยตรง
- ใน Packet Tracer เรียกว่า `FastEthernet0` หรือ `Fa0`

**ฝั่ง Switch**

- Switch มีพอร์ต Ethernet หลายช่อง เช่น 24 หรือ 48 ช่อง
- แต่ละพอร์ตมีหมายเลข เช่น `Fa0/1`, `Fa0/2` หรือ `Gi0/1`

**วิธีต่อสายจริง**

นำสาย LAN ที่มีหัว RJ-45 เสียบด้านหนึ่งเข้าพอร์ต LAN ของ PC1 และอีกด้านเข้าพอร์ตหมายเลข 1 ของ Switch

```text
PC1                         SW1
[พอร์ต LAN] ── สาย LAN ── [Fa0/1]
   Fa0
```

โดยทั่วไปใช้สาย **Copper Straight-Through** ใน Packet Tracer สำหรับการเชื่อมต่อนี้

### 2. แล้ว `Gi0/0/0` หมายถึงอะไร?

ชื่อ Interface แตกต่างกันตามรุ่นและรูปแบบการติดตั้งอุปกรณ์ ตัวอย่างเช่น

- `Gi0/0` — GigabitEthernet พอร์ตที่มีหมายเลขสองส่วน
- `Gi0/0/0` — GigabitEthernet พอร์ตที่มีหมายเลขสามส่วน มักพบใน Router บางตระกูล

**อย่าจำว่าตัวเลขทุกส่วนมีความหมายเหมือนกันใน Router ทุกรุ่น** เพราะโครงสร้างการตั้งชื่อขึ้นอยู่กับแพลตฟอร์มของอุปกรณ์

### 3. หลักสำคัญ

พอร์ตของ Switch กับ Router ไม่จำเป็นต้องเลขเดียวกัน เช่น

```text
SW1 Gi0/1 ───── Router1 Gi0/0
```

ต่อแบบนี้ได้ตามปกติ เพราะหมายเลขพอร์ตเป็นชื่อที่ใช้อ้างอิง Interface ของอุปกรณ์แต่ละตัว

**จำไว้:** เสียบสายเข้าพอร์ตไหน ก็เลือก Interface ของพอร์ตนั้นตอนตั้งค่าครับ
